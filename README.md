# Car Race Multiplayer

Base project Android (Java + Gradle), support Android 5.0 (API 21) sampai versi terbaru.

## Struktur

- `app/src/main/java/com/carrace/MainActivity.java` berisi semua kode (MainActivity, BackgroundService, BootReceiver)
- `app/src/main/res/` berisi icon, string, dan tema
- `.github/workflows/build-apk.yml` workflow GitHub Actions untuk build APK

## Cara build

1. Push folder ini ke repo GitHub.
2. Buka tab Actions, workflow Build APK jalan otomatis (atau pilih Run workflow).
3. Download artifact `Car Race Multiplayer` dari halaman run tersebut.
